# Raspberry Pi 3 Model B – Traffic Light Controller 🚦

C++ project for controlling a traffic light system using **Raspberry Pi 3 Model B** and GPIO pins.

The project demonstrates the implementation of traffic light logic for an embedded system, developed as a university assignment.

---

## 🛠 Technologies
- **C++**
- **Raspberry Pi 3 Model B**
- **GPIO**
- **Linux**
- **WiringPi / GPIO libraries**

---

## ⚙️ Features
- Traffic light control logic
- GPIO pin manipulation
- Time-based light switching
- Multiple implementations showing project evolution
- Embedded systems and hardware–software interaction

---

## 📂 Project Structure
- `firstTrafficLightController.cpp`  
  Initial implementation of the traffic light logic

- `seconTrafficLightController.cpp`  
  Improved version with better timing and control

- `third_FINAL_TrafficLightController.cpp`  
  Final version of the traffic light controller

- `TrafficLightController.mp4`  
  Demonstration video of the project in action
